# Baseline CloudTrail Review
Multi-region trail is turned off limiting log coverage to only one region. Log file integrity is not validated because file validation is disabled. There is no log file SSE-KMS encryption because it's not enabled. S3 data events are not being collected because it is not configured. From an attacker's perspective, S3 object-level data activity on a bucket will not be logged. Modification or deletion of an audit log file can't be verified for integrity. Any unusual audit event activity on a different region would not be captured by this trail. The lack of SSE-KMS means less security controls on encrypted data.
